# Osman Berke Yıldırım: academic website

Four pages: Home (portrait, bio, links), CV (PDF preview), Publications, Calendar (read backwards from the current year to Year 1).

## What to edit

- `content.js`: name, bio, links, publications, calendar entries.
- `cv.pdf`: put your CV here (replace the file to update the CV page).
- `photo.jpg`: put your portrait here. Without it, initials are shown.

Dates are `"YYYY-MM"`. Empty values are hidden. Do not put contact details here that you do not want public.

## Publishing

Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
